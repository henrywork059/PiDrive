## Root cause
The GUI and Mission 1 expose separate camera, AI/selected model, motor, arm and disk properties, but operators must inspect several panels to explain disabled actions. In Mission 1 the camera is *intentionally not yet constructed* until the route stage and a selected model is *not the same as a loaded detector*. A naive preflight could initialize the camera/motors/servos, treat mock simulation as physical readiness, or change settings/trigger preview simply by being opened. A new dock card would also disrupt accepted compact panels and saved layout.

## Files changed and exact behavior
1. **New** `CustomDrive/custom_drive/preflight.py`: a pure component-owned formatter supporting general GUI and Mission 1, with read-only `shutil.disk_usage` and no other I/O. Both produce **seven** rows: mode, camera, model, motor and safety, arm, disk, HTTP reachability. `gui` uses existing camera.get_config, motor.get_config, object-detection `get_status(include_models=False)`, arm.status and control safety; color-only detector is correctly labelled usable **without** a TFLite model. Model state `ready` is still not inference verified. `mission` uses existing camera only if already created; **None** is labelled expected/deferred until route stage and is **never started** just for preflight. Selected model vs already-loaded model is distinct; arm disabled, unavailable real hardware and **simulated** are separate states. Motor GPIO presence does not authorize movement; latched safety remains latched. Mode still says `simulation-running` vs `hardware-adapter-running` when mission active. ## Known limits / required release gate
- Actual preflight **GET** is read-only; ordinary Flask application creation already initializes existing services by design. Checking a hardware adapter is **not** a motor/servo motion test. - Network means current browser HTTP reachability only; PiBooter/network diagnostics handle actual Wi-Fi/router/internet. Disk query is an advisory capacity read, not proof of write permission. No raw paths, secrets or config details enter new preflight rows.
